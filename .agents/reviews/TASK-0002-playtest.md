- **ขอเข้าใช้งาน (O2):** ไม่มีช่องเลือกบทบาท · อีเมลนอกโดเมนถูกปฏิเสธด้วยข้อความไทยชัด · รายการหน่วยงานโผล่หลังพิมพ์อีเมลมหาวิทยาลัย (บอกชื่อมหาวิทยาลัยให้) · สรุปข้อผิดบนสุด+ใต้ช่อง+focus ไปช่องแรก · กดส่งซ้ำเร็ว ๆ ได้คำขอเดียว · ประกาศความเป็นส่วนตัวครบ (วัตถุประสงค์ ระยะเวลาเก็บ ผู้เห็น สิทธิ) · login ขณะรอ = "บัญชีนี้กำลังรอผู้ดูแลอนุมัติ" (EN: "This account is awaiting administrator approval")

- **เชิญ (O1):** ลิงก์แสดงครั้งเดียว + ปุ่มคัดลอก (clipboard ตรงลิงก์) + วันหมดอายุ · token อยู่ใน fragment และถูกลบจากแถบที่อยู่ทันทีที่เปิด · หน้าตั้งรหัสสรุปชื่อผู้ใช้/มหาวิทยาลัย/บทบาท/วันหมดอายุ · รหัส <8 ถูกห้าม · ตั้งรหัสแล้วเข้าระบบทันที · ลิงก์ใช้ซ้ำ/หลังออกใหม่/หลังยกเลิก/ยกเลิกระหว่างผู้ใช้เปิดหน้าค้าง = ข้อความเดียว "ลิงก์เชิญไม่ถูกต้องหรือหมดอายุแล้ว — ขอลิงก์ใหม่จากผู้ดูแลระบบ" · ผู้เชิญได้แจ้งเตือนเมื่อผู้ถูกเชิญเข้าใช้
- **ระงับ/เปิดใช้:** dialog อธิบายผล ("งานที่มอบหมายไว้ยังอยู่ และเปิดใช้อีกครั้งได้ภายหลัง") · รหัสถูก = "ถูกระงับ… ติดต่อผู้ดูแลระบบของมหาวิทยาลัย" รหัสผิด = ข้อความทั่วไป (ไม่เปิดเผยสถานะ) · ไม่มีปุ่มระงับตัวเอง/super admin · ไม่มีปุ่มลบบัญชีที่เคยใช้งาน
- **แจ้งเตือนมีปลายทาง:** ทดสอบ 17 ชนิด ปลายทางถูกทั้งหมด (ตารางด้านบน) · กดแล้วรายการอ่านแล้ว+panel ปิด · ความเห็นเปิดแท็บความเห็นให้เอง · แผนปรับปรุงไฮไลต์แถว · panel บนมือถือเต็มจอ · คีย์บอร์ด: Enter เปิด, Esc ปิด focus กลับกระดิ่ง · EN ใช้ `messageEn` ทุกรายการที่ดู
- **Workflow ครบวงจร 6 บทบาท** (chair → lecturer → chair → faculty_qa → chair → dean → faculty_qa → assessor → chair) เดินได้ผ่านแจ้งเตือนอย่างเดียว · dialog ทุกขั้นสรุปข้อควรระวัง (ช่องว่างวิกฤต/PII) ก่อนยืนยัน · ส่งกลับบังคับเหตุผล · ล็อกแล้วแสดง hash + "ตรวจแล้ว เนื้อหา SAR ตรงกับที่ล็อก" · ปุ่มส่งผลประเมินปิดจนให้คะแนนครบ 8/8 · ส่งออก .docx สำเร็จ
- **ทนการป่วน:** `<script>` ใน SAR แสดงเป็นข้อความ, อีโมจิ/ไทยปนอังกฤษ/ตัวเลขติดลบบันทึกได้, refresh กลางทางข้อความยังอยู่ (autosave), กดบันทึกสองครั้งได้รายการเดียว (คำขอ/เชิญ/แผนปรับปรุง), สลับภาษา+ธีมมืด+ตัวอักษรใหญ่มากกลางฟอร์มข้อมูลไม่หาย และ error summary แปลตาม
- **สิทธิ์จาก URL:** lect1→admin, assessor→actions/metrics/curriculum, uadmin2→ข้อมูลมหาวิทยาลัยอื่น ได้หน้า "ไม่มีสิทธิ์" ไม่เห็นข้อมูลทุกกรณี · ไม่ login → เด้ง /login
- **มือถือ 390:** ไม่มี h-scroll ทุกหน้าที่ลอง (ขอเข้าใช้งาน, หน้าหลัก, คำขอ, ผู้ใช้, หน้าเขียนข้อ) · drawer มีปุ่ม "ปิด" และตัวนับงาน
- ไม่มี console error / pageerror ตลอดทุกสคริปต์
