## โจทย์ (จากเจ้าของ)
ปรับโปรเจกต์ (re-project) จาก EduFlow (ระบบโรงเรียน) เป็น **AUN-QA Copilot** ตาม spec: `.agents/spec/AUN-QA_Copilot_Spec.md` (source of truth)
- ส่วนไหนใช้ต่อได้ → ใช้ของเดิม · ส่วนไหนต้องเปลี่ยน → เปลี่ยน
- **คงรูปแบบ frontend เดิม** (ธีม warm/cream, ฟอนต์ Cormorant Garamond + DM Sans/Sarabun, CSS ล้วนใน globals.css, layout/shell เดิม) — ปรับได้ถ้าจำเป็นตามดุลยพินิจ
- ใช้ researcher หาข้อมูลเพิ่มได้ · ตรวจละเอียดถี่ถ้วน · ทำต่อเนื่องจนจบโดยไม่ต้องรอเจ้าของกดยืนยัน

## การตัดสินใจของ orchestrator (ให้ architect ยืนยัน/ปรับใน ADR)
1. **คง stack เดิม**: Next.js 14 App Router + TypeScript + CSS ล้วน (ไม่ย้ายไป Tailwind/shadcn เพราะเจ้าของต้องการคงหน้าตาเดิม)
2. **Data layer MVP = localStorage store pattern เดิม** (`readJSON/writeJSON`, `hasPermission`) เพราะยังไม่มี Supabase/credential — แต่ต้อง **ออกแบบ interface ให้ย้ายไป PostgreSQL/Supabase ได้** และเขียน SQL schema + RLS + trigger ตามหัวข้อ 8 ของ spec เป็นไฟล์ migration (ใช้ในเล่ม + อนาคต)
3. **AI service กลาง** = Next.js Route Handler (`app/api/ai/**`) + lib กลาง: PII redaction → provider → post-check (citation/ตัวเลข) → บันทึก ai_run. Provider: Claude API ถ้ามี `ANTHROPIC_API_KEY` ใน env; ถ้าไม่มี → **offline deterministic provider** (rule/template-based) ให้เดโม่ได้เสมอ. ห้ามอ่าน `.env` — ใช้ `.env.example`
4. **Unit test = Vitest**, E2E = Playwright (ติดตั้งแล้ว)
5. ของเดิมที่ไม่เกี่ยว (wallet/shop/ebook/booking/tutoring/QR attendance/ปพ./ตารางสอนโรงเรียน/parent) → ถอดออกจาก route/nav; ตัดสินว่าจะลบหรือย้ายไป `legacy` ตามแผน architect (อยู่ใน git ย้อนได้)
6. ทำตาม MVP หัวข้อ 14 ก่อน แบ่งเป็น Milestone เพื่อให้ resume ได้ทุกจุด
