## โจทย์ (จากเจ้าของ)
"redesign หน่อย อยากให้สวยกว่านี้ ให้ทันสมัยกว่านี้" — เจ้าของเลือก (2026-10-25):
- สไตล์: **Modern SaaS สะอาด** (แนว Linear/Notion/Vercel — พื้นขาว/เทาอ่อน, การ์ดขอบบาง, sans ทั้งหมด, accent สีเดียว, มี dark mode)
- ขอบเขต: **ทั้งระบบ** — landing, login, shell/เมนู, ทุกหน้าทำงานของทุก role (8 role)
- Stack: **ย้ายไป Tailwind CSS + shadcn/ui** (แทน CSS ล้วนใน globals.css; ยกเลิกข้อ "คงธีม cream/brown" ของ TASK-0001) → ต้องมี ADR-UI-002

## ข้อจำกัด
- ไม่แตะ business logic / data layer / AI service — เปลี่ยนเฉพาะ presentation
- ฟังก์ชันและ flow ทุกอย่างต้องเหมือนเดิม: vitest + Playwright E2E เดิมต้องผ่าน (ปรับ selector ได้ถ้าจำเป็น โดยไม่ลดสิ่งที่ทดสอบ)

- diagram + เล่ม: ทำหลังสุดตามกฎ (จดสิ่งที่ต้องอัปเดตใน Log)

## รอบ 2 — เจ้าของสั่ง redesign ใหม่ (2026-10-26)
