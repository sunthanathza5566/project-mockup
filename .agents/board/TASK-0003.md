## โจทย์ (จากเจ้าของ)
1. สร้างตัวอย่างทดสอบการใช้งานเว็บ **ทุก role** พร้อม **วิดีโอ** ครอบคลุมทุกกระบวนการ (ให้ agent ทำ)
2. สร้าง **ไฟล์ doc** อธิบายแต่ละ role มีหน้าที่อะไร เชื่อมถึงกันยังไง
3. เจ้าของลองเล่นเอง: หลัง "บันทึก" และ "ส่งตรวจ" → **ประธานไม่ได้รับแจ้งเตือน** (อาจเป็นบั๊ก หรือเจ้าของเล่นผิดขั้น) → ต้องหาสาเหตุให้ชัด แก้ถ้าเป็นบั๊ก และอธิบายใน doc ถ้าเป็นวิธีใช้
4. จำลองข้อมูลทดสอบสำหรับ **ทุกเคสที่อาจเกิด**
5. เตรียมพร้อมรับงาน **Figma ใหม่** ที่เจ้าของจะส่งมาให้แก้ (ยังไม่ต้องแก้ UI)
6. เสร็จแล้ว **ตรวจสอบซ้ำอีกครั้ง → merge เข้า master → push**
