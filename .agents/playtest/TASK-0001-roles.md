## Usability task: ผู้ใช้ใหม่ อัปโหลดหลักฐาน + ผูก 1 ข้อ (เป้า < 3 นาที ไม่มีคู่มือ)
- เส้นทางที่สั้นสุด 5 คลิก: หลักฐาน -> + เพิ่มหลักฐาน -> ชื่อ -> เลือกไฟล์ -> เลือกข้อในรายการ -> บันทึก (สคริปต์ <1 วิ)
- จุดที่คนใหม่ต้องเดา/พลาด: (1) หน้า "คลังหลักฐาน" เห็น 6 ตัวกรอง + ตาราง 17 แถวก่อนปุ่ม (2) ฟอร์ม 11 ช่อง ต้องกรอกเฉพาะชื่อ+ไฟล์+ข้อ (3) เลือก "ข้อ" ใน list ตัดข้อความ + multi-select (4) ช่อง "รอบ" อยู่ไกล่ด้านบนฟอร์ม label บอก "ต้องเลือกรอบด้านบนด้วย" (5) ถ้าลืมแนบ -> toast หายเร็ว (BUG-P4) -> คาดเวลาคนจริง 2-4 นาที: **อาจผ่านเป้า แต่ไม่แน่นอนสำหรับผู้ใช้ 50+ ที่ไม่เคยใช้**; หลังบันทึกมี toast "เพิ่มหลักฐาน E-1.2-01 แล้ว" (ดี) แต่หน้าเลื่อนกลางตาราง
- ทางลัดที่มีแล้วแต่ซ่อน: ผูกจากหน้าข้อ (dropdown) เมื่อหลักฐานอยู่ในคลังแล้ว

## UX Issues -- ข้อเสนอ 10 ข้อที่คุ้มที่สุด
1. **Home แยกตาม role เป็น "สิ่งที่ต้องทำตอนนี้" (card ใหญ่ 1-3 ใบ)**: อาจารย์ = ข้อที่ต้องเขียน/ถูกส่งกลับ; chair = ข้อรอตรวจ + ปุ่มส่ง QA; fqa/dean = รอบที่รอ; assess = เริ่มประเมิน; ซ่อนข้อความมอบหมายที่ไม่เกี่ยว (แก้ pain หลักทุก role)
2. **ลดเมนูตาม role + ชื่อภาษาคน**: อาจารย์เหลือ 4 (งานของฉัน, หลักฐาน, ข้อทั้งหมด, ส่งออก) ส่วนที่เหลือรวม "เพิ่มเติม"
3. **หน้าข้อ: stepper 4 ขั้น** (1 ผูกหลักฐาน -> 2 เขียน/ให้ AI ร่าง -> 3 ให้คะแนน -> 4 ส่งตรวจ) + ปุ่มส่งตรวจ sticky ด้านล่าง; รวมคอลัมน์ขวา AI/ความเห็นเป็นแท็บ
4. **เตือนก่อนส่ง/อนุมัติ**: checklist ก่อนส่งตรวจ (มีเนื้อหา? มีหลักฐาน? ให้คะแนน?) และ dean/fqa เห็นสรุป "ยังมี gap วิกฤต N" ก่อนกดล็อก
5. **Feedback ใกล้จุดกด**: toast ค้างนานขึ้น (5-6 วิ), ย้ายใกล้ปุ่ม, validate inline (กรอบแดง + ข้อความใต้ช่อง) ในฟอร์มหลักฐาน/login
6. **แก้ session ข้ามแท็บ** (localStorage + expiry) และ autosave on blur/beforeunload + แสดง "ยังไม่บันทึก" เมื่อพิมพ์ค้าง
7. **ฟอร์มหลักฐานแบบ 3 ช่อง**: ชื่อ -> แนบไฟล์/ลิงก์ -> เลือกข้อ (autocomplete ค้นหา) ส่วนเหลือพับ "รายละเอียดเพิ่มเติม"; เปลี่ยน "ไฟล์ (ถ้ามี)" ให้ตรงกฎ
8. **Noti ที่ role ถัดไป**: ส่งให้ fqa/dean/assessor เมื่อรอบเปลี่ยนสถานะ + badge จำนวน "รอท่าน" บนเมนูรอบประเมิน; ปุ่ม "อ่านแล้ว" -> "ทำเครื่องหมายว่าอ่านแล้ว"
9. **แดชบอร์ดรอบ: เน้นความคืบหน้า** (3 ตัวเลข + แถบ % อนุมัติ) พับ gap list; อธิบาย "ความพร้อม 28%" และคำว่า วิกฤต/เตือน; ลด wall แดง ใช้สีเตือนอุ่นแทนแดงเข้ม
10. **หน้า loading/404/ธีมตกค้าง**: เปลี่ยน loading หลัง login เป็น spinner/skeleton ธีมเดียวกัน (ตัด emoji + หน่วง 1.5 วิ), ลิงก์ default สีน้ำเงินใช้สีธีม, หน้า 404 มีปุ่มกลับ, ขยายฟอนต์ตัวเล็ก (ข้อความช่วย 0.8rem) และเพิ่ม tooltip/ความหมาย PDCA, Offline, verdict

## สิ่งที่ทำงานดี (ใช้เป็นผลทดสอบได้)
- login ไว (~1.5 วิรวม loading) trim ช่องว่างได้, ข้อความ error ภาษาไทยชัด, panel บัญชีทดสอบกดเติมให้
- กฎ RBAC: ข้ามหน้า/แก้ owner ไม่ได้, segregation of duties (ผู้เขียนอนุมัติเองไม่ได้ พร้อมข้อความอธิบาย), อนุมัติแล้ว read-only พร้อมเหตุผล
- ส่งกลับแก้ต้องระบุเหตุผลก่อน (ปุ่มยืนยัน disabled) และเจ้าของได้ noti พร้อมเหตุผลทันที
- ส่งออกแม่แบบ/นำเข้า Excel: preview, ตรวจ+บอกแถวผิดภาษาไทย, ไม่เก็บไฟล์/ข้อมูลรายคน
- กันไฟล์ผิดชนิด/ไฟล์ซ้ำ, ตรวจรหัสอ้างอิงหลักฐานที่ไม่มีอยู่
- ปุ่มทำซ้ำ (double-click) ไม่ส่งซ้ำ, Back หลัง logout ปลอดภัย, มือถือไม่ล้นแนวนอนหน้าหลัก
- lock + hash บอกชัด "ตรวจแล้ว เนื้อหา SAR ตรงกับที่ล็อก"
