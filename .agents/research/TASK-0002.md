## คำตอบ (ยืนยันแล้ว) — พร้อมหลักฐาน

### 1) Tailwind v3 vs v4 + shadcn CLI
- shadcn ปัจจุบัน (`shadcn@latest` = 4.22.1) init เป็น Tailwind v4 และ "All components are updated for Tailwind v4 and React 19", "We've removed the forwardRefs" [ยืนยัน S1]
- เอกสาร shadcn ฝั่ง v3: "If you are using Tailwind v3, use `shadcn@2.3.0`" [ยืนยัน S2]; 2.3.0 ออก 2025-01-28 ก่อนยุค v4 (npm time) [ยืนยัน]
- React 19 เท่านั้นที่ส่ง `ref` เป็น prop ให้ function component ได้ [ยืนยัน S3] — คอมโพเนนต์ registry `new-york-v4` (เช่น button) เป็น function ไม่มี forwardRef [ยืนยัน: `ui.shadcn.com/r/styles/new-york-v4/button.json`] ส่วน registry style `new-york` (v3) ยังใช้ `React.forwardRef` [ยืนยัน: `v3.shadcn.com/r/styles/new-york/button.json`, `ui.shadcn.com/r/styles/new-york/dialog.json`]
- Tailwind v4 ต้องการ Chrome 111 / Safari 16.4 / Firefox 128 [ยืนยัน S4]; v3 สาย LTS ล่าสุด = **3.4.19** (npm dist-tag `v3-lts`) [ยืนยัน]
- Peer deps รองรับ React 18 ทั้งหมด [ยืนยัน npm registry]: next-themes 0.4.6, lucide-react 1.61.0, recharts 3.10.1 / 2.15.4, @radix-ui/react-dialog 1.3.1, @radix-ui/react-select 2.4.1
- tailwind-merge: `latest` 3.7.0 (สาย v4), dist-tag `tailwind-merge-2` = **2.6.1** (สาย v3) [ยืนยัน npm]
- **กับดักที่พบ [ยืนยันจากการอ่านโค้ด CLI]**: `shadcn@2.3.0` ดึง base color จาก `REGISTRY_URL ?? "https://ui.shadcn.com/r"` แล้วเขียน tailwind config เป็น `hsl(var(--x))` (`package/dist/index.js` ของ tarball 2.3.0) แต่ `https://ui.shadcn.com/r/colors/zinc.json` ตอนนี้ส่งค่าเป็น **oklch** → ได้ `hsl(oklch(...))` = สีพัง; ส่วน `https://v3.shadcn.com/r/colors/zinc.json` ยังส่งเป็น HSL channel (`"0 0% 100%"`)

### 2) Setup + อยู่ร่วมกับ globals.css เดิม
- Next 14: `npm i -D tailwindcss postcss autoprefixer` + `npx tailwindcss init -p`, `content` ต้องครอบ `app/`, `components/` (+ เพิ่ม `context/`, `lib/` ของเรา), directive `@tailwind base/components/utilities` ใน globals.css [ยืนยัน S5]
- Preflight v3 ล้าง margin ของ h1–h6/p, ทำ h1–h6 เท่าข้อความปกติ, ลบ bullet ของ ul/ol, ตั้ง `border-width:0; border-style:solid` ทุก element, ให้ img/svg เป็น `display:block` [ยืนยัน S6] → **ชนกับ CSS เดิมแน่** ตรงที่พึ่งค่า default ของ element (หัวข้อ, list, svg inline ใน Icon/TrendChart)
- ปิดได้ด้วย `corePlugins: { preflight: false }` [ยืนยัน S6]
- dark mode v3: `darkMode: 'selector'` (แทน `'class'` ตั้งแต่ 3.4.1) [ยืนยัน S7]
- shadcn theming: คู่ตัวแปร `--primary` / `--primary-foreground`, ชุดตัวแปร background/foreground/card/popover/primary/secondary/muted/accent/destructive/border/input/ring/chart-1..5 + `--radius` (ค่าปัจจุบัน 0.625rem) [ยืนยัน S8, registry JSON]

### 3) Dark mode ไม่กระพริบ
- next-themes ฉีด script ตั้ง attribute บน `<html>` ก่อนหน้าโหลด → "will not flash"; dev mode อาจยังกระพริบ [ยืนยัน S9]
- App Router: ThemeProvider เป็น client component, ครอบ children ใน `<body>`, ใส่ `suppressHydrationWarning` ที่ `<html>`; shadcn แนะนำ `attribute="class" defaultTheme="system" enableSystem disableTransitionOnChange` [ยืนยัน S9, S10]
- `useTheme` เป็น `undefined` บน server → UI ที่ขึ้นกับธีม (ปุ่มสลับ) ต้องรอ mounted หรือ render placeholder [ยืนยัน S9]
- `enableColorScheme` (default true) ตั้ง color-scheme ให้ฟอร์ม native; มี `nonce` สำหรับ CSP [ยืนยัน S9]

### 4) ฟอนต์ผ่าน next/font
- next/font self-host, "No requests are sent to Google by the browser", ใช้ `variable: '--font-x'` แล้วผูกใน `tailwind.config` `fontFamily.sans`; ฟอนต์ที่ไม่ใช่ variable ต้องระบุ `weight`; ต้องระบุ `subsets` เมื่อ preload [ยืนยัน S11]
- ฟอนต์ที่มีใน Next 14.2.35 (`node_modules/next/dist/compiled/@next/font/dist/google/font-data.json`) [ยืนยัน]:
  | ฟอนต์ | weights | subsets | variable |
  |---|---|---|---|
  | IBM Plex Sans Thai / **IBM Plex Sans Thai Looped** | 100–700 | thai, latin, latin-ext | ไม่ (ต้องระบุ weight) |
  | Noto Sans Thai | 100–900 | thai, latin | **ใช่** (wght, wdth) |
  | Noto Sans Thai Looped | 100–900 | thai, latin | ไม่ |
  | Anuphan | 100–700 | thai, latin | **ใช่** (wght 100–700) |
  | Sarabun | 100–800 | thai, latin | ไม่ |
  | Inter | 100–900 | latin (ไม่มี thai) | ใช่ |
  | **Geist** | — | — | **ไม่มีใน Next 14.2.35** → ต้องใช้ npm `geist` 1.8.2 (peer `next >=13.2`) [ยืนยัน npm] |
- Tailwind v3 default line-height: `text-sm` 14/20px (1.43), `text-base` 16/24 (1.5) [ยืนยัน S12] — คอมโพเนนต์ shadcn ใช้ `text-sm` เป็นหลัก → แน่นเกินสำหรับไทย; ปรับได้ใน `theme.fontSize` แบบ tuple `[size, {lineHeight}]` [ยืนยัน S12]
- W3C Thai Layout Requirements (Draft Note 2026-03-20) หัวข้อ line height ยัง "(tbc)" ไม่มีตัวเลข; ยืนยันแค่ว่าสระประกอบมีได้ถึง 4 glyph + วรรณยุกต์ ล้อมพยัญชนะได้ 3 ด้าน [ยืนยัน S13]

### 5) Icon + chart
- lucide-react 1.61.0 peer React ^18 [ยืนยัน] — ตรงกับที่ `Icon.tsx` คัด path มาจาก Lucide อยู่แล้ว
- shadcn chart = Recharts; หน้าเอกสารปัจจุบันเป็น Recharts v3 [ยืนยัน S14]; registry style `new-york` (v3/React 18) **pin `recharts@2.15.4`** (`ui.shadcn.com/r/styles/new-york/chart.json`) แต่ `v3.shadcn.com/r/styles/new-york/chart.json` ระบุ `recharts` ไม่ pin (จะได้ 3.x) [ยืนยัน]; สีผ่าน `--chart-1..` ใน `:root`/`.dark`, `accessibilityLayer` ให้คีย์บอร์ด/screen reader [ยืนยัน S14]

### 6) Design token SaaS
- Radix Colors 12 ขั้น: 1–2 พื้น, 3–5 พื้น component (ปกติ/hover/active), 6–8 เส้นขอบ/focus, 9–10 สีทึบ, 11–12 ตัวอักษร; ขั้น 11/12 บนพื้นขั้น 2 รับประกัน APCA Lc 60/90 [ยืนยัน S15]
- Vercel Geist: 100–300 พื้น, 400–600 เส้นขอบ (ใช้เทาทึบเป็นค่าเริ่ม), 700–800 พื้น contrast สูง, 900–1000 ตัวอักษร; "Background 2 should be used sparingly" [ยืนยัน S16]
- shadcn base colors: Neutral, Zinc, Slate, Stone, Gray [ยืนยัน S8]

### 7) Radix vs Playwright
- `locator.selectOption`: "If the target element is not a `<select>` element, this method throws an error" [ยืนยัน S17] → shadcn `Select` (Radix) ใช้ไม่ได้กับ 16 จุดนี้
- Radix Select: trigger `role="combobox"`, content `role="listbox"`, item `role="option"`, มี native select ซ่อน (`SelectBubbleInput`) สำหรับ form [ยืนยัน S18 source]; content อยู่ใน Portal ไป `body` [ยืนยัน S19]
- shadcn มีคอมโพเนนต์ **`native-select`** (ห่อ `<select>` จริง) ใน registry v4 [ยืนยัน `ui.shadcn.com/r/styles/new-york-v4/native-select.json`]
- Radix Dialog: `role="dialog"`, ไม่ใส่ `aria-modal` แต่ใช้ `hideOthers` (aria-hidden ทุกอย่างนอก content) [ยืนยัน S20 source]; **AlertDialog ใช้ `role="alertdialog"`** และ focus ปุ่ม Cancel ตอนเปิด [ยืนยัน S21 source] → `getByRole('dialog')` 14 จุด **จะหาไม่เจอถ้าเปลี่ยนเป็น AlertDialog**
- `getByRole` ไม่นับ element ที่ hidden ตาม ARIA เป็นค่าเริ่ม [ยืนยัน S17] → ขณะ Radix modal เปิด ทุกอย่างนอก dialog เป็น aria-hidden

## อนุมาน / ยังไม่แน่ใจ
- [อนุมาน] Tailwind v4 + Next 14 ทำงานได้ทาง `@tailwindcss/postcss` แต่ไม่คุ้ม เพราะ shadcn v4 components สมมติ React 19 (ไม่มี forwardRef) → บน React 18 การใช้ `asChild` ที่ Slot ส่ง ref ให้ Button จะได้ ref = null + warning → Popover/Tooltip/DropdownMenu วางตำแหน่งจาก trigger ไม่ได้ ไม่ได้ทดลองรันจริง
- [อนุมาน] วิธีเลี่ยงกับดักสี oklch: รัน `REGISTRY_URL=https://v3.shadcn.com/r npx shadcn@2.3.0 init` หรือไม่ใช้ init แล้วเขียน `components.json` + `lib/utils.ts` + ตัวแปร HSL เอง (ทีมจะกำหนด token เองอยู่แล้ว) — ยังไม่ได้รัน; frontend-dev ต้องตรวจ CSS ที่ได้ว่าไม่มี `oklch(` ใน `hsl(...)`
- [อนุมาน] ใช้รูปแบบ HSL channel (`--primary: 222 47% 11%`) กับ v3 เพื่อให้ opacity modifier (`bg-primary/90`) ที่คอมโพเนนต์ใช้ทำงาน
- [อนุมาน] ลำดับไฟล์ระหว่างย้าย: `@tailwind base;` → `@tailwind components;` → CSS เดิม (ไม่อยู่ใน @layer) → `@tailwind utilities;` ให้ utility ชนะ `.aq-*` ที่ specificity เท่ากัน; หรือปิด preflight ช่วงแรกแล้วเปิดเมื่อลบ CSS เดิมหมด
- [อนุมาน] rem-based utility ของ Tailwind ขยายตาม `html{font-size}` ของ PrefsInit อยู่แล้ว (ฟีเจอร์ ก-/ก/ก+ ไม่พัง) — ต้องให้ ui-inspector ตรวจ
- [อนุมาน] line-height ไทยยังไม่มีแหล่งวัดตรง (W3C ยัง tbc) — คงข้อเสนอเดิม body 1.6–1.75, หัวข้อ ≥1.35 จาก `standards/ui-ux.md` 1.1
- [อนุมาน] ฟอนต์: Inter ไม่มีกลิฟไทย → ใน stack `Inter, <ฟอนต์ไทย>` ไทยจะ fallback ไปตัวที่สองอัตโนมัติ แต่ขนาด/ความสูงตัวไทย-อังกฤษอาจไม่สมดุล; ใช้ฟอนต์ไทยที่มีละตินในตัวตัวเดียวปลอดภัยกว่า
- [อนุมาน] `next/font/google` ดาวน์โหลดไฟล์ตอน build → เครื่อง build ต้องออกเน็ตได้
- ไม่ได้เปิดหน้า Linear/Notion โดยตรง — อ้างอิงระบบ token จาก Radix Colors + Vercel Geist แทน

## ข้อแนะนำต่อ architect
1. เลือก **ทางเลือก A** และระบุเวอร์ชัน pin ใน ADR-UI-002; ห้าม `shadcn@latest`; init ด้วย `REGISTRY_URL=https://v3.shadcn.com/r` หรือเขียน config เอง; ตรวจว่าไม่มี `oklch` ใน CSS ที่ generate
2. ย้ายทีละส่วน: เริ่มด้วย `preflight:false` + utility หลัง CSS เดิม → ย้ายหน้าจนไม่มี `aq-*` → เปิด preflight แล้วลบ globals.css เดิม (AC: ไม่มีคลาส `aq-` ค้างตอนจบ ยกเว้นที่ E2E พึ่ง ซึ่งต้องย้ายไป `data-testid` ก่อน)
3. ฟอนต์: ใช้ฟอนต์ไทยที่มีละตินในตัวผ่าน `next/font` (เลิก `<link>`): ตัวเลือกที่สอดคล้องหลักฐานเดิม (ผู้ใช้วัยสูงชอบแบบมีหัว) = **IBM Plex Sans Thai Looped** (400/500/600/700) หรือ **Noto Sans Thai Looped**; ถ้าเน้นหน้าตา SaaS แบบไม่มีหัว = **Anuphan** หรือ **Noto Sans Thai** (variable). ถ้าต้องการ Inter/Geist คู่ ให้ใช้กับตัวเลข/โลโก้เท่านั้น (Geist ต้องใช้ npm `geist`). ตั้ง `fontSize` ใน tailwind config ให้ `sm`/`base` มี line-height ≥1.6 และให้ ui-inspector render จริงก่อนล็อก
4. Dark mode: next-themes `attribute="class"` + `darkMode:'selector'`, ลบ `viewport.colorScheme:'light'`, ปุ่มสลับรอ mounted, ตรวจ contrast AA ทั้ง 2 ธีม (ใช้ขั้น 11/12 สำหรับข้อความ), AC ต้องรวม "PrefsInit กับ class dark ไม่เขียนทับกัน"
5. Icon: เปลี่ยน `Icon.tsx` เป็น wrapper ของ `lucide-react` คง API `name/size/label` เดิม (aria-hidden เมื่อไม่มี label)
6. Chart: **คง TrendChart (SVG เอง) แล้ว restyle ด้วยตัวแปร `--chart-*`** — มีพฤติกรรมเฉพาะ (direct label, tick, ไม่พึ่งสี) ที่ยืนยันแล้ว; ถ้าจะเปลี่ยนเป็น shadcn chart ต้อง pin `recharts@2.15.4` และเขียนเทสต์ใหม่ (เพิ่ม dependency ใหญ่ ประโยชน์น้อย)
7. Token: neutral = zinc หรือ slate (shadcn base) + accent สีเดียว (กำหนดจาก palette ใน ui-ux.md 4.2 ที่คำนวณ contrast แล้ว), radius 0.5–0.625rem, เงาบาง (shadow-sm) + เส้นขอบ 1px แทนเงาหนัก, density: control สูง ≥40px (target size ตาม ui-ux.md 2 ใหญ่กว่า default shadcn `h-9`=36px)
8. Playwright: (ก) ใช้ **native-select** แทน Radix Select ทุกจุดที่เทสต์ใช้ `selectOption` (39 `<select>`) → ไม่ต้องแก้ 16 จุด; (ข) dialog ยืนยัน/แจ้งเตือนใช้ Radix **Dialog** (ไม่ใช่ AlertDialog) หรือคง `DialogContext` แล้ว restyle → `getByRole('dialog')` ยังผ่าน; (ค) คง `data-testid` ทุกตัว + selector class/id ที่เทสต์ใช้ (`a.aq-skip`, `.aq-count`, `textarea.aq-textarea--prose`, `#app-sidebar`, `summary`) หรือย้ายเป็น testid ใน subtask เดียวกับหน้านั้น; (ง) Toast: คง `ToastContext` เดิม restyle (ไม่เปลี่ยนเป็น sonner) เว้นแต่ตรวจ selector แล้ว; (จ) Dialog ของ Radix ต้องมี Title (ใช้ VisuallyHidden ได้) ไม่งั้นมี console error
