- ฟอนต์: TH Sarabun New / เนื้อหา 16 pt [ต้องตรวจสอบกับคู่มือสาขา: KKU CS = 14] / "บทที่ N"+ชื่อบท 18 pt หนา กึ่งกลาง / หัวข้อ 1.1 = 16 pt หนา / หัวข้อ 1.1.1 = 16 pt ธรรมดา (ปกเล่ม: ชื่อเรื่อง 20 pt หนา)
- ระยะบรรทัด: เดี่ยว (Single) · จัดข้อความแบบกระจายไทย · ย่อหน้าบรรทัดแรก 0.5 นิ้ว · หัวข้อย่อยเข้าอีกครั้งละ 0.25 นิ้ว [ต้องตรวจสอบกับคู่มือสาขา]
- ระยะขอบ: บน 1.5" ซ้าย 1.5" ล่าง 1" ขวา 1" (ตรงกันทุกคู่มือ)
- กระดาษ A4 80 แกรม · เลขหน้ามุมบนขวา ห่างขอบ 1" · หน้าแรกของแต่ละบท/บรรณานุกรม/ภาคผนวก นับแต่ไม่พิมพ์เลข
- เลขหน้าส่วนนำ: ก ข ค … [ต้องตรวจสอบกับคู่มือสาขา: MFU ไม่ใส่เลข] ; เนื้อหาเริ่มเลข 1 ที่หน้าแรกบทที่ 1
- ลำดับส่วนนำ: ปกนอก → ปกใน → ใบรับรอง → บทคัดย่อ → Abstract → กิตติกรรมประกาศ → สารบัญ → สารบัญตาราง → สารบัญรูป → คำอธิบายสัญลักษณ์และคำย่อ [ต้องตรวจสอบกับคู่มือสาขา: NU วางกิตติกรรมก่อนบทคัดย่อ]
- หัวข้อบท: `# บทที่ 3 วิธีดำเนินการวิจัย` / หัวข้อย่อย: `## 3.1 ...` / `### 3.1.1 ...`
- รูป: "รูปที่ <บท>.<ลำดับ> <คำอธิบาย>" ใต้รูป กึ่งกลาง / ตาราง: "ตารางที่ <บท>.<ลำดับ> <คำอธิบาย>" เหนือตาราง ชิดซ้าย [ต้องตรวจสอบกับคู่มือสาขา: คำว่า รูป/ภาพ และนับต่อบทหรือตลอดเล่ม]
- คำอธิบายรูป/ตารางห้ามขึ้นต้นด้วย "แสดง…" ; รูปที่ยืมจากแหล่งอื่นต้องมีที่มาใต้รูป ; ตารางไม่ใช้เส้นแนวตั้ง ; ตารางข้ามหน้าใส่ "(ต่อ)"
- ตารางใน Markdown: ใส่บรรทัด `Table: ตารางที่ x.y ...` ไว้เหนือตาราง (pandoc ใช้เป็นคำบรรยายตาราง)
- บทคัดย่อ ≤ 1 หน้า + คำสำคัญ 3–5 คำ ; กิตติกรรมประกาศ ไม่ระบุวันที่ ไม่ใส่คำนำหน้านาม ; ปกไม่ใส่คำนำหน้านาม
- อ้างอิง APA 7 นาม-ปี: ผู้แต่งไทยใช้ชื่อ+นามสกุลเต็ม ปี พ.ศ. · ผู้แต่งอังกฤษใช้นามสกุล ปี ค.ศ. · 2 คน "และ"/"&" · ≥3 คน "และคณะ"/"et al." · องค์กร [ตัวย่อ] ครั้งแรก · ไม่ใช้ "สืบค้นเมื่อ"/"Retrieved from" ยกเว้นหน้าที่เปลี่ยนตลอด · DOI เป็น URL · บรรณานุกรมลงผู้แต่งได้ถึง 20 คน · เรียงไทยก่อนอังกฤษ · ตัวอย่างอยู่ใน thesis-th.md หัวข้อ 5
- ศัพท์เทคนิค: ครั้งแรก "ไทย (English)" แล้วใช้ชื่อเดียวตลอด ; ใช้บุรุษที่สาม "ผู้วิจัย" ; ห้ามกล่าวเกินตัวเลขที่วัดจริง
- ตัวเลขใช้เลขอารบิก ; ใช้ "ร้อยละ" ในเนื้อความ
