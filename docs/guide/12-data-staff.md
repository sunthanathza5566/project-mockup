# คู่มือเจ้าหน้าที่ข้อมูล (data_staff)

> บัญชีทดสอบ: `data1` / `demo1234` — คุณสุดา เก็บข้อมูล (ขอบเขตทั้งคณะ)
> อ่าน [ภาพรวม](00-overview.md) ก่อน ถ้ายังไม่รู้จักคำว่า SAR, PDCA, หลักฐาน `E-x.x-nn`

เจ้าหน้าที่ข้อมูลดูแล "ตัวเลข" และ "เอกสาร" ของหลักสูตร: นำเข้าตัวชี้วัดย้อนหลัง (สำคัญมากกับเกณฑ์ 8) และอัปโหลดหลักฐานเข้าคลัง

## ทำอะไรได้ / ทำอะไรไม่ได้
| ทำได้ | ทำไม่ได้ |
|---|---|
| กรอก/แก้ค่าตัวชี้วัดรายปี พร้อมเป้าหมายและ benchmark | เขียน SAR หรือให้คะแนนตนเอง |
| นำเข้าตัวชี้วัดรายปีและผลการศึกษารายรุ่นจาก Excel | ใช้ AI ร่าง/แปล SAR |
| เพิ่มหลักฐาน ผูกกับข้อ จัดการหลักฐานที่มี PII | ยืนยันหลักฐาน (เป็นงานของประธาน/QA คณะ) |
| ให้ AI แนะนำข้อและขั้น PDCA ของหลักฐาน | อนุมัติหรือส่งต่อรอบ |
| ดูรอบประเมิน แดชบอร์ด ข้อมูลหลักสูตร ส่งออกเอกสาร | แก้ข้อมูลหลักสูตร (PLO/รายวิชา) |

## เมนูที่เห็น
หน้าหลัก · รอบประเมิน · หลักฐาน · ส่งออกเอกสาร · หลักสูตร · ตัวชี้วัด · แผนปรับปรุง · คลังเกณฑ์ AUN-QA

## เริ่มจากหน้าหลัก
หน้าหลักมีการ์ดทักทาย ปุ่ม "ทำงานถัดไป" และรายการ "สิ่งที่ต้องทำตอนนี้" เช่น "จัดการข้อมูลส่วนบุคคลในหลักฐาน 1 ชิ้น" (ปุ่ม "ไปทำ") มุมขวาบนมีปุ่ม "เพิ่มหลักฐาน" ถ้าไม่มีงาน จะแนะนำให้ "อัปเดตตัวชี้วัดล่าสุดไว้ ระบบจะตรวจแนวโน้มให้" พร้อมปุ่ม "ไปหน้าตัวชี้วัด" หน้าตาโดยรวมดู [ภาพรวม หัวข้อ 5](00-overview.md#5-หน้าตาและการใช้งานพื้นฐาน)

## 1. นำเข้าตัวชี้วัดรายปีจาก Excel
ใช้เมื่อมีข้อมูลหลายปี เช่น อัตราส่วนอาจารย์ต่อนักศึกษา จำนวนผลงานวิจัย จำนวนคำร้องอุทธรณ์
1. เมนู **ตัวชี้วัด** (`/app/metrics`) เลือกหลักสูตรที่ช่องด้านบน
2. กดกล่อง **"นำเข้าจากไฟล์ Excel"** เพื่อกาง (อยู่ใต้หัวหน้า เหนือกราฟ)
3. ส่วน **"ตัวชี้วัดรายปี"** → กด **"ดาวน์โหลดแม่แบบ (.xlsx)"** ไฟล์มีแผ่นวิธีใช้และแผ่นรหัสตัวชี้วัด
4. กรอก 1 แถว = ตัวชี้วัด 1 ปี (รหัส ปี ค่า และถ้ามี เป้าหมาย ค่า benchmark แหล่ง benchmark) บันทึกไฟล์
5. กด **"เลือกไฟล์ที่กรอกแล้ว"** ระบบตรวจไฟล์และแสดงตารางผลตรวจ: ผ่าน n แถว / ไม่ผ่าน n แถว พร้อมเหตุผลรายแถว และแถวที่จะ "แทนที่ค่าเดิม"
6. ถ้ามีแถวไม่ผ่าน จะขึ้น "มี n แถวไม่ผ่าน จะถูกข้าม — แก้ไฟล์แล้วอัปโหลดใหม่ได้"
7. กด **"ยืนยันนำเข้า…แถวที่ผ่าน"** → ขึ้น "นำเข้าแล้ว: เพิ่ม x · แทนที่ y · ข้าม z แถว"

สาเหตุที่แถวไม่ผ่าน: ไม่รู้จักรหัสตัวชี้วัด · ปีไม่ใช่จำนวนเต็มในช่วง 1900–2700 · ค่าไม่ใช่ตัวเลข · ค่าเป็นเปอร์เซ็นต์แต่นอกช่วง 0–100 · ค่าติดลบ · ปีซ้ำในไฟล์เดียวกัน
คำเตือนที่ไม่บล็อก: มีปีขาดกลางช่วง · ข้อมูลไม่ครบ 3 ปี (ทำให้แสดงแนวโน้มไม่ได้ กฎ R3)

## 2. นำเข้าผลการศึกษารายรุ่น (cohort)
ใช้คำนวณอัตราสำเร็จการศึกษา อัตราพ้นสภาพ และเวลาเรียนเฉลี่ยต่อรุ่น (เกณฑ์ 8.1)
1. ในกล่องนำเข้า ส่วน **"ผลการศึกษารายรุ่น (cohort)"** ใส่ **"เวลาเรียนตามหลักสูตร (ปี)"** (ปริญญาตรีมักเป็น 4)
2. กด **"ดาวน์โหลดแม่แบบ (.xlsx)"** แล้วกรอก 1 แถวต่อนักศึกษา 1 คน ใช้ 3 คอลัมน์
   - `cohort` รุ่น (ปีที่เข้า)
   - `status` = `graduated` / `dropped_out` / `enrolled` (หรือภาษาไทย จบ / ลาออก หรือ พ้นสภาพ / กำลังศึกษา)
   - `years_to_graduate` จำนวนปีที่ใช้จนจบ (เฉพาะผู้จบ)
3. กด **"เลือกไฟล์รายคน"** ระบบแสดงตารางต่อรุ่น: จำนวน จบตามเวลา พ้นสภาพ % จบ % พ้นสภาพ เวลาจบเฉลี่ย
4. กด **"ยืนยันนำเข้าผลรวม n รุ่น"**

ข้อควรรู้
- **ถ้ามีแถวผิดแม้แถวเดียว ระบบจะไม่นำเข้าอะไรเลย** (เพื่อไม่ให้อัตราคลาดเคลื่อนโดยไม่รู้ตัว) แก้ไฟล์ตามรายการแถวที่ไม่ผ่านแล้วอัปโหลดใหม่
- ระบบอ่านไฟล์ในเบราว์เซอร์ อ่านเฉพาะ 3 คอลัมน์ข้างบน **ไม่อ่านชื่อหรือรหัสนักศึกษา** และเก็บแค่ผลรวมต่อรุ่น ไม่เก็บไฟล์ต้นฉบับ
- ถึงจะไม่เก็บ แต่ **ไฟล์ที่ใช้ในเดโม่ต้องเป็นข้อมูลสมมติ** เท่านั้น

## 3. กรอกหรือแก้ค่าทีละรายการ
1. หน้า **ตัวชี้วัด** → กด **"+ เพิ่ม/แก้ค่าตัวชี้วัด"**
2. เลือกตัวชี้วัด ปี ใส่ค่า (และเป้าหมาย/benchmark/แหล่ง benchmark ถ้ามี) แล้วบันทึก
3. ในตาราง "ค่าตัวชี้วัดรายปี" แก้ค่าที่มีอยู่ได้จากปุ่มแก้ไขในแถว

## 4. อ่านกราฟแนวโน้ม
ส่วน "แนวโน้ม 3–5 ปี" แสดงกราฟต่อตัวชี้วัด: เส้นค่าจริง เป้าหมาย และ benchmark แกนตั้งบอกหน่วย แกนนอนเป็นปีการศึกษา (พ.ศ.) ค่าทุกปีดูได้จากตารางด้านล่าง

![หน้าตัวชี้วัดพร้อมกราฟ](../../.agents/screenshots/TASK-0002/final-metrics-light-1440.png)

บนจอแคบหรือเมื่อเลือกตัวอักษรใหญ่ ตาราง "ค่าตัวชี้วัดรายปี" จะเรียงเป็นการ์ดทีละแถว ปุ่มแก้ไข/บันทึก/ยกเลิกยังอยู่ครบ

## 5. อัปโหลดหลักฐาน
วิธีเหมือนคู่มืออาจารย์ ดู [คู่มืออาจารย์ หัวข้อ 1](11-lecturer.md#1-เพิ่มหลักฐาน) — สรุปสั้น ๆ
1. หน้าหลัก → "เพิ่มหลักฐาน" (หรือเมนู หลักฐาน → "+ เพิ่มหลักฐาน")
2. ใส่ชื่อ → แนบไฟล์/ลิงก์/ข้อความ → พิมพ์เลขข้อแล้วเลือก → (ไม่บังคับ) เลือกประเภทและขั้น PDCA → "บันทึกหลักฐาน"
3. ถ้าขึ้น "พบข้อมูลส่วนบุคคล" ให้จัดการต้นฉบับแล้วกด "ทำเครื่องหมายว่าจัดการแล้ว" ในหน้ารายละเอียดหลักฐาน
4. ข้อที่ส่งตรวจหรืออนุมัติแล้วมีป้าย "ล็อกแล้ว" ผูกหลักฐานเพิ่มหรือเลิกผูกไม่ได้ ดู [คู่มืออาจารย์: ข้อที่ล็อกแล้ว](11-lecturer.md#ข้อที่ล็อกแล้ว-ผูกหลักฐานไม่ได้)

## เคล็ดลับ
- เตรียมข้อมูลย้อนหลังอย่างน้อย 3 ปี (ดีที่สุด 5 ปี) ไม่อย่างนั้นข้อที่ต้องใช้แนวโน้มจะติดกฎ R3
- ใส่ค่า benchmark และแหล่งที่มาทุกครั้งที่มี ข้อที่ต้องเทียบเคียงจะติดกฎ R8 ถ้าไม่มี
- เปลี่ยนหลักสูตรที่ช่องด้านบน ระบบจะล้างไฟล์ที่ตรวจค้างไว้ให้เอง ป้องกันการนำเข้าผิดหลักสูตร
- ไฟล์ตัวชี้วัดรายปีที่ตรวจแล้วต้องกดยืนยันภายใน 30 นาที ถ้าเกินให้เลือกไฟล์ใหม่

## ปัญหาที่พบบ่อย
| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| หากล่องนำเข้าไม่เจอ | กล่องพับอยู่ | กดหัวกล่อง "นำเข้าจากไฟล์ Excel" ใต้หัวหน้า |
| แถวไม่ผ่าน "ไม่รู้จักรหัส" | พิมพ์รหัสตัวชี้วัดเอง | คัดลอกรหัสจากแผ่น codes ในแม่แบบ |
| cohort นำเข้าไม่ได้ทั้งไฟล์ | มีแถวผิดอย่างน้อย 1 แถว | ดูรายการ "แถว n: เหตุผล" แก้แล้วอัปโหลดใหม่ |
| กดยืนยันแล้วขึ้นว่าไม่พบ | ผลตรวจหมดอายุ (เกิน 30 นาที) หรือกดซ้ำ | เลือกไฟล์ใหม่อีกครั้ง |
| กด "ให้ AI แนะนำ" แล้วขึ้นข้อผิดพลาด | มหาวิทยาลัยนั้นปิดการใช้ AI | ผูกข้อเองจากหน้ารายละเอียดหลักฐาน |
| เปิดหน้าเขียนข้อแล้วแก้ไม่ได้ | บทบาทนี้ไม่ได้เขียน SAR | ส่งข้อมูลให้อาจารย์เจ้าของข้อ หรือผูกหลักฐานให้แทน |
| ผูกหลักฐานกับข้อไม่ได้ ขึ้น "ล็อกแล้ว" หรือ "ผูกไม่ได้" | ข้อนั้นส่งตรวจหรืออนุมัติแล้ว | แจ้งประธานหลักสูตรให้ส่งข้อกลับแก้ไขก่อน |
