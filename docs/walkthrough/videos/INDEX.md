# วิดีโอ walkthrough ทุกบทบาท (TASK-0003)

วิดีโอทั้งหมดอัดจากระบบจริงด้วย Playwright (เบราว์เซอร์ Chromium 1280x720) และ**ผ่านการตรวจผลอัตโนมัติทุกขั้น**: กระดิ่งเพิ่มจริง ข้อความยืนยันถูกต้อง สถานะเปลี่ยนจริง
บนจอมี **คำบรรยายภาษาไทย** ด้านล่าง ป้าย **"บทบาท: … (username)"** มุมซ้ายบน ป้ายฉาก/ขั้น และกรอบสีส้มไฮไลต์ปุ่มก่อนกดทุกครั้ง

- รูปแบบไฟล์: `.webm` (VP9) — เปิดด้วย Chrome / Edge (ลากไฟล์ใส่หน้าต่าง) หรือ VLC · ffmpeg ของ Playwright ไม่มีตัวเข้ารหัส H.264 จึงไม่ได้แปลงเป็น .mp4
- ข้อมูลทั้งหมดเป็นข้อมูลสมมติ · รหัสผ่านบัญชีเดโม่ทุกบัญชี `demo1234`

## วิธีอัดใหม่

ในโฟลเดอร์ `eduflow-next`:

```bash
# build + start ให้อัตโนมัติ (port 3917)
npx playwright test -c playwright.walkthrough.config.ts
# ใช้เซิร์ฟเวอร์ที่รันอยู่แล้ว (เช่น next start -p 3990)
E2E_REUSE=1 E2E_PORT=3990 npx playwright test -c playwright.walkthrough.config.ts
# อัดเฉพาะบางวิดีโอ
E2E_REUSE=1 E2E_PORT=3990 npx playwright test -c playwright.walkthrough.config.ts -g "V03|V10"
# บีบอัด (VP9 crf 40) ไฟล์ที่อัดใหม่
node e2e/walkthrough/compress-videos.mjs
```

- spec อยู่ที่ `eduflow-next/e2e/walkthrough/V*.spec.ts`, helper คำบรรยายที่ `e2e/walkthrough/narrate.ts`
- เทสต์ที่ผ่านจะคัดลอกวิดีโอมาที่โฟลเดอร์นี้เอง (ทับไฟล์เดิม) แล้วต้องรัน `compress-videos.mjs` อีกครั้ง (ไฟล์ `.compressed.json` จำว่าไฟล์ไหนบีบแล้ว)
- config หลัก `playwright.config.ts` ไม่รันโฟลเดอร์ walkthrough (`testIgnore`)
- ใช้เวลารันทั้งชุด ~25 นาที (มี slowMo 300 ms และหยุดให้อ่านคำบรรยาย)
