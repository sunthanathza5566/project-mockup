# Scenario seed — ชุดข้อมูลทดสอบทุกเคส (TASK-0003 S4)

ข้อมูลทั้งหมดเป็น**ข้อมูลสมมติ** (ชื่อมีคำว่า "(สมมติ)", อีเมลโดเมน `*.example`, PII ในหลักฐานเป็นของปลอม) · รหัสผ่านทุกบัญชี **`demo1234`**

## วิธีใช้

```ts
import { listScenarios, loadScenarioPack, resetToStandardSeed } from '@/lib/mock-data/aunqa/scenarios';

listScenarios();                    // รายการเคส: id, titleTh, descriptionTh, accounts, paths, expectTh
await loadScenarioPack();           // รีเซ็ตเป็น seed มาตรฐาน แล้วโหลด "ทุกเคส" (= loadScenarioPack('all'))
await loadScenarioPack('deadlines'); // รีเซ็ต แล้วโหลดเคสเดียว
await resetToStandardSeed();        // กลับเป็น seed มาตรฐาน (รวมส่วนเสริม F4)
```

- ใช้ได้เฉพาะในเบราว์เซอร์ (ข้อมูลอยู่ใน `localStorage` ของเบราว์เซอร์นั้น) — เปิดอีกเบราว์เซอร์/หน้าต่างไม่ระบุตัวตน จะไม่เห็นข้อมูลนี้
- ทุกครั้งที่โหลด/รีเซ็ต **ข้อมูลเดิมทั้งหมดถูกล้าง** และ **session ถูกล้าง** → ต้องล็อกอินใหม่
- `loadScenarioPack` คืน `{ loaded, links, ms }` — `links` มีลิงก์เชิญ (`/invite#t=…`) ที่สร้างใหม่ทุกครั้ง แสดงได้ครั้งเดียว ต้องเก็บจากผลการโหลด
- โหลดทุกเคสใช้เวลาประมาณ 5 วินาที (วัดใน Node) และใช้พื้นที่ localStorage ประมาณ 2.1 ล้านตัวอักษร (โควตาเบราว์เซอร์ประมาณ 5 ล้าน)
- ทุกเคสสร้างผ่าน API จริงของ `lib/api` (แจ้งเตือน / ประวัติการอนุมัติ / audit / version เกิดครบเหมือนผู้ใช้กด) — **ข้อยกเว้นเดียว:** คณะ + หลักสูตรของมหาวิทยาลัยที่ 2 ไม่มี API สร้าง จึงเขียนผ่าน `save()` แบบเดียวกับ `lib/api/init.ts`
- กำหนดส่งคิดจาก "วันที่โหลด" (เช่น เลยกำหนด 2 วัน) — โหลดใหม่เพื่อให้ตรงกับวันนี้
- แจ้งเตือนของรอบย้อนหลังถูกทำเป็น "อ่านแล้ว" ยกเว้นแจ้งเตือนของขั้นล่าสุด (ให้เห็นที่กระดิ่ง)
